# 互动表盘制作

把用户的素材与交互意图转成目标设备实际支持的交付物。优先沿用已确认的人物、构图和操作方式，依据型号、固件、手机系统与工具能力调整实现。

## 找到工程与能力

先复用会话已知信息。确认设备完整型号、固件或 watchOS 版本、绑定手机系统，以及当前请求是预览、制作还是安装。缺少尺寸或打包格式时，先核实，不以相似型号代替。

技能需搭配完整 `interactive-watchface-kit` 仓库进行打包或批量导出。运行本技能内的只读定位器：

```bash
python3 "<技能目录>/scripts/locate_kit.py"
```

可传入 `--root "<仓库目录>"`，或设置 `WATCHFACE_KIT_ROOT`。定位器只读取目录，不下载、安装、启动服务或执行仓库脚本。独立安装技能后找不到仓库时，可继续核实能力与设计；需要代码工具时，使用用户提供的完整仓库路径或取得完整仓库，再继续。不要把 `../../` 当成稳定安装路径。

定位成功只说明找到目录结构，还需检查输出中本次适配所需的 `resources.*.exists`。文件缺失时先补齐相应仓库内容，再读取对应 profile、项目配置和相关脚本 `--help`。已有项目以自身 profile 为准，保留用户明确的参数与素材。不要把 profile 中的型号文字改成新型号，就声称完成适配。

| 设备路径 | 接着读取 | 交付边界 |
| --- | --- | --- |
| 小米 n67；当前适配为小米手环 9 Pro | [小米原生表盘](references/xiaomi-n67.md) | 经格式检查的原生工程及包；编译器可用性须实查 |
| Apple Watch 系统照片表盘 | [Apple Watch 照片素材](references/apple-watch.md) | PNG 照片与导入说明，不生成伪造的 `.watchface` |
| 其他设备或未覆盖的版本 | [新设备适配](references/device-adaptation.md) | 先形成能力判断；证据足够后再创建适配 |

## 先把视觉和行为做好

- 仅使用有权用于本次用途的素材。用户提供的图片与私人参考库不随公共工具仓库分发；公开示例使用原创或有适当许可的素材。自写代码的 MIT 许可不替代图片、字体或第三方图标许可。
- 以实际屏幕比例制作预览。人物默认等比适配，脸、手肘、裙摆、大腿等用户要求保留的部位不能靠裁切消失；需要留白时扩展背景或缩放整体。先检查源图本身是否已经截断。
- 多状态沿用同一人物锚点、尺度和四肢位置。用中间帧、遮罩或过渡组织变身，不用错位切图代替动作。数据层避开脸、手和关键装饰；在原生像素尺寸检查可读性。
- 将亮屏、熄屏、自动动画、点击和传感器触发列为独立状态，说明同时发生时的优先级。传感器示例值须标明模拟，未知值不能伪造成正常测量。
- 用户只要预览时交付可查看的预览，不提前生成安装包。用户已要求制作或安装时，继续完成相应准备与校验，无需重复询问同一授权。

## 验证与交付

验证真实结果：原生尺寸截图、状态切换、边界输入、输出格式和素材完整度。设备支持脚本时，检查亮屏启动、隐藏停止、再次唤醒恢复；有 AOD 时单独检查其资源和格式标志。

把“源码检查”“生成包检查”“真机试用”分别记录，不能用前两者替代最后一项。仅在工具成功产出后称已打包；仅在用户或设备实测后称已在真机生效。交付与具体版本对应的文件、最短安装步骤及尚未验证的部分。

技能的调用不授予外部发布、上架、发送或安装到设备的权限。沿用当前会话已有授权；不把作者以前发布此仓库的授权带到新的用户任务。预览优先用静态文件或现成预览入口，需要本地服务时采用可退出的单次会话。
