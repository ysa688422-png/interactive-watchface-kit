# 小米 n67 原生互动表盘

## 入口与适用范围

从定位器返回的仓库根读取：

- `profiles/xiaomi-band-9-pro.json`：具体设备能力、屏幕和格式配置。
- `templates/xiaomi-n67/`：原创示例、Lua 与 AOD 模板。
- `scripts/create_project.py`：创建独立项目；先读 `--help` 确认参数。
- `scripts/validate_project.py`：项目校验。
- `scripts/pack_xiaomi.py`：打包入口；先读 `--help` 和依赖说明。

已知此适配以小米手环 9 Pro 的 336 × 480 屏幕为目标。不要把 n67 的头结构、Lua 接口或安装方式推广到其他小米型号。固件变化时检查配置和格式证据；应用商店工具的系统要求也需按当时版本确认。

```bash
python3 "<仓库>/scripts/validate_project.py" --project "<项目目录>"
python3 "<仓库>/scripts/pack_xiaomi.py" \
  --project "<项目目录>" --output "<输出文件.bin>" \
  --packer "<用户提供的打包器路径>"
python3 "<仓库>/scripts/validate_project.py" \
  --project "<项目目录>" --package "<输出文件.bin>"
```

命令存在不代表编译器已安装。打包器须由用户提供，并核实用途与许可；工具不会自动下载或随包提供外来编译器。若原生打包依赖缺失或许可未明确，保留已完成工程与预览，说明具体缺口；不要复制未授权编译器、给 ZIP 改 `.bin` 后缀，或报告未执行的成功。

## AOD 头结构是关键约束

对于本仓库验证过的 n67 格式：

- 头中 `0x1E` 是 flags，不是布尔值；`0x04` 位表示包含 AOD。
- 只有 AOD 功能位需要设置时，`headerFlags=4`。设置为 `1` 不能表达 AOD，可能使设备退回系统样式。
- 另有功能位时按格式证据保留其他位，并合入 `0x04`，不能直接清空。
- 此适配的原生数字元素左对齐值为 `align=1`，profile 中对应 `native_digit_align_left`。这是数字布局参数，不是包体字节对齐，也不与头 flags 混用。
- AOD 资源、原生元素和头标志必须同时存在并一致。只制作黑底花朵图片不构成可用 AOD。

确认实际 profile 和打包器采用的字段名与序列化结果，不能只检查配置中的文字。解包后读取头与 AOD 元素，核对尺寸、资源索引和引用是否有效；能往返打包时检查结果一致。

AOD 默认使用低亮度、低覆盖率的静态元素和设备时间。不要把普通面 Lua 自动动画直接假定为息屏可运行。

## 动画、点击与心率

明确普通面状态、过渡态及稳定态；分别配置心率阈值、未知值策略、过渡时间和点击行为。把主题素材与行为参数分开，便于替换角色。

- 若约定“心率大于 120”，边界应为 `HR > 120` 触发、`HR <= 120` 恢复；新的项目读取用户或 profile 参数，不固定为 120。
- 心率来自手环最近测量结果。读取数值不等于发起持续采样；不要把 UI 更新频率说成传感器测量频率。
- `nil`、缺失、无效文本及设备定义的无效哨兵值应进入明确的未知态。缺省显示 `--`，不触发新的高心率事件；当前过渡如何收尾、是否保留上次稳定态须按项目策略落实，不能靠 `or 0` 意外决定。
- 重复读取同一高值不应反复从头启动变身。测试阈值两侧、恰好等于阈值、未知与恢复有效值、过渡中点击、变身中熄屏和再次唤醒。
- 用目标运行时真实生命周期回调启动和停止动画。停止计时器、解绑或暂停回调要符合运行时 API；预览中的 `requestAnimationFrame` 不能证明设备生命周期正确。
- 若加滞回或延迟以减少阈值附近抖动，须与用户约定的触发条件一致，不能悄悄改变“大于即触发”的要求。

## 视觉与包校验

统一多帧人物尺度、躯干锚点和四肢落点，检查所有帧的 alpha 边界。用背景补位或局部修复解决原素材缺口，避免人物在画面中突然水平截断。时钟遮光层放在人物后面；检查过渡中是否遮住头盔、脸或手。

至少检查常态、点击态、变身稳定态、过渡中间帧、最大位数数据、未知心率/电量及 AOD。以 336 × 480 原生截图判断字号，放大图只用于检查细节。

对生成包校验资源引用、图片尺寸与像素、脚本语法及关键状态行为。若格式工具支持，独立解析与解包重打包能发现序列化错误；它们仍不替代真机验证。新的包使用项目指定的有效身份，避免与其他安装版本混淆；不复制作者个人表盘 ID。

## 安装说明

优先沿用用户已经成功使用的发送工具及当前手机，核实该版本支持本设备和格式。选择 `.bin` 发到已连接手环，成功后在手环本地表盘中选择新表盘。不要擅自换绑、恢复出厂或购买付费工具。

小米官方手环 9 Pro 说明给出的 AOD 设置位于“设置 → 显示与亮度 → 息屏显示”（本机菜单为准），可选择智能或定时。未提供内嵌 AOD 的表盘可能显示默认样式；不要编造一个独立的自定义素材选项，也不要据此断定所有故障都出在菜单。新包仍回退默认样式时，先检查包内标志、资源与实际选中的版本。

官方来源：[小米手环 9 Pro 息屏显示说明](https://www.mi.com/tw/support/faq/details/KA-514933/)、[英文 AOD 说明](https://www.mi.com/global/support/faq/details/KA-515555/)。涉及新型号或菜单变化时重新核实。
